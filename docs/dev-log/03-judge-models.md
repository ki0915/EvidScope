> 증거 계층 제품과 에이전트 모니터링·콘솔 UI는 다른 파트에서 다룬다.
>
> 출처 표기: 커밋은 `sha7`, 저장소 문서는 `docs/...`, 저장소 밖 작업 기록은 "작업 메모", 감사 문서는 "적대적 감사 문서(claude.ai, 비공개)"로 적는다.
> 계산하거나 추론한 값은 "(추정)" 또는 "(계산)"으로 표시한다. 학습·평가 데이터는 모두 설계(합성)·공개 데이터이며, 사람이 검토한 데이터는 없다.
>
> 자주 나오는 용어
> - **QLoRA**: 큰 모델 본체는 4비트로 줄여 고정해 두고, 작은 덧붙임 가중치(LoRA 어댑터)만 학습하는 방식. 12GB 그래픽카드에서도 8B급 모델을 학습할 수 있다.
> - **판단 보류(abstain)**: 확신이 낮을 때 답하지 않고 규칙·사람에게 넘기는 것. "답한 것의 정확도(정밀도)"와 "답한 비율(coverage, 답변율)"을 함께 본다.
> - **보정(calibration)**: 모델이 말하는 확신도가 실제 맞힐 확률과 맞도록 맞추는 일. "90% 확신"이면 실제로 10번 중 9번 맞아야 한다.
> - **게이트(gate)**: 모델을 화면·운영에 올리기 전 통과해야 하는 기준 묶음(위협을 하나도 놓치지 않기, 규칙만 쓰는 것보다 나을 것 등).
> - **처음 보는 유형(unseen)**: 학습에 그 계열이 전혀 나오지 않은 시나리오 묶음으로 만든 평가 세트.
> - **경보 이름 가림(masked) / 규칙 출력 제거(stripped)**: 같은 세션에서 규칙 경보 이름을 중립 이름으로 바꾸거나, 규칙이 붙인 소견을 아예 빼고 모델에게 보여 주는 변형. 모델이 경보 이름에 기대는지 행동 내용을 읽는지 가린다.

- **어떤 문제였나:** 감사 시스템이 다루는 에이전트 기록에는 명령·경로·내부 정보가 들어 있다. 외부 클라우드 모델에 보내면 데이터 경계와 비용 문제가 생긴다.

- **해결 방법:** 로컬 Ollama + 실행 단위 자격 + 서명 원장에 남는 요청·결과·사람 검토. 모델 응답은 언제나 제안이며 사건·법률 상태를 바꿀 수 없다.

- **포트폴리오 한 줄:** 데이터가 PC 밖으로 나가지 않는 로컬 AI 자문 경로를 설계하고, 모델이 실패해도 감사 기능은 그대로 동작하도록 권한 경계를 분리했다.

## 이 트랙에서 배운 점

- **만점은 먼저 의심한다.** "처음 보는 60세션 1.0"은 평가 패턴이 학습에 섞인 누수였고, 모델 없는 한 줄 허용 목록이 같은 점수를 냈다. 이후 모든 회차에 "모델 없는 단순 기준선"과 누수 검사 4종을 게이트에 넣었다.
- **라벨이 지름길을 허용하면 모델은 지름길을 배운다.** 정답이 경보 코드 조합만으로 정해지자 모델은 행동을 읽지 않았다. 같은 경보에 정답이 다른 대조 쌍(설정 읽기/수정, 자기 브랜치/공유 브랜치 강제 푸시)과 경보 이름 가림·규칙 출력 제거 변형이 이를 깼다.
- **확신도는 말이 아니라 측정해야 한다.** 말로 낸 확신도는 "high"만, 고정 0.9/0.1만 나왔다(ECE 0.37). 토큰 확률·판정 헤드 확률로 바꾸고 검증 분할로만 문턱을 고르자 보류가 작동했다(JEV 답변율 54%→100%, 정확도 유지).
- **보정은 검증 분할의 분포에 좌우된다.** 보류 행이 55%인 검증 분할로 고른 문턱은 28%인 시험에서 답변율을 4.5~14.5%로 떨어뜨렸다. 검증은 시험과 같은 분포로 만든다.
- **판단 보류는 정확도의 일부다.** "모두 답하는 99%"가 아니라 "답한 것의 99% + 나머지는 규칙·사람에게"로 정의해야 현실적이고, 답변율을 함께 보고해야 한다.
- **작은 시험으로는 99%를 말할 수 없다.** 25/25의 95% 하한은 약 88%. 오류 0으로 99%를 말하려면 약 300건이 필요해, 시험을 350세션×3 변형으로 키웠다.
- **외부 시험은 따로 지킨다.** 우리 답안지에서 100%여도 R-Judge는 57~87%였다. 외부 세트와 겹치는 공개 데이터는 학습에서 기계적으로 빼야 의미 있는 숫자가 나온다.
- **모델이 틀리면 안 되는 일은 코드가 한다.** 조항은 서명된 매핑 표가 계산하고, 모델은 규칙 경보를 지울 수 없으며, 경보를 낮추려면 두 모델이 동의해야 한다. 학습이 기록 변조 탐지를 지운 사고에서 나온 원칙이다.
- **모델 크기보다 역할과 반복 속도.** 보안 특화 8B 한 개보다 작은 Qwen3-4B(빠른 반복)와 확률 판정 JEV-9B를 역할로 나눈 쪽이 처음 보는 유형에서 결과가 좋았다.
- **데이터 경계를 먼저 정하면 외부 자원도 쓸 수 있다.** 합성·공개 데이터만 임대 GPU로, 실제 세션은 PC에만 두는 규칙 덕분에 "로컬 우선"을 깨지 않고 학습 자원을 늘렸다.
