LOCAL QUICKSTART

모델 없이도 실행됩니다

Node.js 24.15 이상 25 미만을 준비합니다. 수집·분석·감사 화면은 일반 코드로 동작합니다.

npm run init
npm start

# 별도 터미널
npm run demo

감사 화면: http://127.0.0.1:8082
.local/config.json의 인간 역할 토큰으로 접속합니다.

실제 토큰·DB·서명키는 Git에 올리지 않습니다. 현재 문서 뷰어는 인증이나 운영 API에 연결하지 않습니다.
