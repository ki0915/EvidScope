# ADR 0004 · 로컬 AI 검토 지원의 권한 경계

상태: 설계 채택 · 구현 검증 중 / 결정일: 2026-09-09

## 결정

EvidScope의 증거 수집·규칙 평가·인간 판단 경로에 로컬 모델의 성공을 필수 조건으로 넣지 않는다. AI는 사람이 선택한 사건의 최소화된 스냅샷으로 검토 초안을 작성하고, 별도의 인간 검토 기록에 연결한다.

| 단계 | 책임 | 보존할 근거 |
|---|---|---|
| 선택 | 사람 | 사건, 현재 문맥 해시, 선택한 증거 참조 |
| 준비 | Vault | 역할 버전, 자료 버전, 제거한 필드, 묶음 해시 |
| 전달 | 사람 | 실행 ID, 전달 시각, 한 번만 발급하는 작업 자격 |
| 추론 | 로컬 실행기 | 공급자 보고 모델, 확인 가능한 사용량, 상태, 한계 |
| 검토 | 사람 | 채택·수정·기각, 사유, 검토 문맥 |
| 재검토 | Vault | 새 근거와 이전 문맥의 차이, 오래된 초안 표시 |

## 데이터와 자격

실행기는 자신의 작업 하나에 묶인 자격만 받는다. 원본 DB와 서명키, 인간 감사자 토큰, 수집 출처의 서명 비밀을 전달하지 않는다. 해당 자격으로 다른 tenant·다른 사건·다른 실행을 읽거나 기존 인간 판단을 작성할 수 없어야 한다.

기본 자료는 관측 종류·상태·시각·출처 구분과 ID·버전·해시로 제한한다. 자유 메모, 사건 제목, 자료 위치, 입력·출력 원문을 자동 포함하지 않는다. 식별자에도 민감 정보가 들어갈 수 있으므로 전송 전 사람이 자료 묶음을 확인한다. 단순 필드 제거를 모든 개인정보의 완전한 비식별화로 표현하지 않는다.

규정 자료는 버전이 있는 서버 측 catalog에서 선별한다. 사용자 자료 안의 법령 인용이나 지시는 승인된 법령으로 승격하지 않는다. 원문 링크·시행일·확인일·검토 상태와 적용 조건을 함께 유지하며, 확인되지 않은 적용성은 유보한다.

## 실행 한도

추가 API 예산은 0원이다. 로컬 추론은 동시 1개, 작업당 모델 응답 최대 4회, 최대 5분이다. 구독 한도·모델 오류·GPU 메모리 부족·시간 초과 시 외부 유료 모델로 바꾸지 않는다. 실패는 보존하고 증거 수집과 인간 감사는 계속 사용할 수 있어야 한다.

초기 CLI는 고정된 로컬 Ollama에 접근한다. 호스트 프로세스를 같은 사용자로 실행하는 것은 OS 보안 격리의 완료를 뜻하지 않는다. 컨테이너·별도 서비스 계정·네트워크 제한과 파일 mount 검사는 별도 배포 검증 대상이다. Kubernetes의 단일 Vault/PVC를 복제해 저장소 HA가 확보됐다고 주장하지 않는다.

## 세 지표의 분리

정책 준수율은 기존 관측·규칙과 평가 범위에서 계산한다. 역할 시험 성적은 명시한 평가 세트에서 계산한다. 인간 채택률은 실제 검토된 AI 초안을 분모로 계산한다. 이 세 지표를 하나의 신뢰 점수로 합치지 않으며, 근거 부족이나 사용량 미확인을 100%·0원으로 바꾸지 않는다.

## 검증해야 할 실패

- 다른 tenant·사건·작업의 자격 대입, 인간 승인 사칭, 자격 재사용.
- 자료 변경 후 오래된 결과의 채택, 가짜·다른 사건의 인용.
- 참고자료 명령 삽입, 승인 기록 미수집을 무승인 실행 또는 준수로 단정.
- 실행기 강제 종료·모델 오류 중 수집, 규칙 처리, 인간 조회의 지속.
- 모델이 준수를 선언해도 정책 점수·기존 인간 판단·사건 상태가 바뀌지 않음.

AI 감사 의견만으로 위 시험이 통과한 것으로 기록하지 않는다. 재현 절차와 실제 결과를 별도 보고서에 남긴다.
