# 에이전트별 정책 현황

에이전트 목록은 테넌트 내부의 인증된 에이전트 수집 출처와 보고된 actor를 함께 식별한다. 같은 이름이라도 출처가 다르면 다른 행이다. 모델 이름, 마지막 에이전트 수신 시각, 행동 수, 참고자료 연결 및 인간 검토 상태를 표시한다. 도구 기록만 있고 에이전트 출처에 연결되지 않은 행동은 목록 비율에서 제외하고 별도 개수로 표시한다. actor는 보고값이며 출처 인증이 실제 에이전트 신원을 입증하지 않는다.

관측 정책 준수율은 **충족 행동 / (충족 행동 + 위반 신호 행동)** 이다. 함께 표시하는 평가 범위는 판정 가능한 행동 / 해당 에이전트의 관측 행동이다. 5개 중 2개만 판정 가능하고 1개가 충족이면 준수율 50%, 평가 범위 40%다. 분모가 0이면 100%가 아니라 산정 불가다.

이 초기 기준의 버전은 `evidscope-observed-policy-v1`이다. 화면 기본은 최근 7일이며 24시간·30일·전체 보존 기간도 선택한다. 사용자별 맞춤 분모와 법적 준수 점수는 제공하지 않는다.

기간은 현재 보존 중인 첫 에이전트 수신 시각을 기준으로 행동을 선택한다. 시작과 종료 경계는 포함하며, 해당 행동의 기간 밖 연관 증거도 최신 평가에 사용한다. 따라서 추이 그래프는 수신 구간별 행동에 대한 현재 평가이며 과거 당시의 판정 이력이 아니다. 에이전트 미귀속 행동은 첫 이벤트 수신 시각으로 별도 집계한다. 파기로 첫 보존 기록이 달라지면 과거 집계가 달라질 수 있다.

`GET /api/agents`는 `range=24h|7d|30d|all`(API 기본 all), `focus=all|violation|unconfirmed|stale|inactive`, `sort=recent|attention|coverage`를 지원한다. `end`는 ISO UTC 종료 시각이며 미래 시각은 거부한다. 상세 조회에 목록의 종료 시각을 전달해 같은 시간 범위를 유지한다. 평가 자체는 조회 시점의 최신 상태다. 상단 카드 수는 검색어와 기간을 반영하고 우선 확인 필터 적용 전의 에이전트 수다. 한 에이전트가 여러 카드에 해당할 수 있다.

상세 추이는 기간별 24·7·30개 구간이며, 전체 보존 기간은 해당 에이전트 관측 범위를 30개로 나눈다. 구간·정책 상태·인간 검토·행동 ID 필터를 함께 적용하고 20개씩 모든 집계 행동에 접근한다. 데이터가 없는 구간은 수신 0이며 안전이나 수집 정상의 증거가 아니다.

- 충족: 최신 전체 평가가 있고 독립 실행, 당시 정책 버전, 등록·권한·사람 승인 관련 근거가 확인되며 위반·누락 신호가 없는 행동.
- 위반 신호: 최신 전체 평가에서 목적지 정책 또는 사용자 룰 위반이 발견된 행동. 다른 근거가 부족해도 관측된 위반 신호 자체는 남긴다.
- 미확인: 신원 귀속이 모호하거나 실행·등록·정책·권한·승인 근거가 부족하거나 전체 평가를 확인할 수 없는 행동. 분류되지 않은 새 평가 코드도 충족으로 간주하지 않는다.
- 평가 대기: 새 근거·정책 변경을 최신 분석이 반영하지 않은 행동.
- 예외 적용: 억제된 신호가 있는 행동. 원본 발견 사항을 유지하며 충족으로 올리지 않는다.

미확인·평가 대기·예외는 비율의 분모에서 제외하지만 각 개수를 바로 옆에 표시한다. 도구 성공률과 정책 준수율은 서로 다르다. 업무 실패도 정책 내에서 발생할 수 있고, 성공한 실제 AI 호출도 권한 근거가 없으면 준수로 계산하지 않는다. 사람의 검토는 별도로 계산하며 새 증거나 기한 만료 시 재검토 상태로 바뀐다.

목록·상세는 조회 사본의 운영 지표다. 증거 무결성은 기존 사건 보고서/서명 원장 검증으로 확인한다. 집계 자료 32MB·5만 행·단일 행 1MB 한도를 넘으면 413을 반환하며 부분 결과로 준수율을 만들지 않는다. 목록 API 페이지 크기는 최대 100행이다. 상세 API는 한도 내 전체 행동을 반환하고 화면에서 페이지를 나눈다. 실제 대규모 운영에서는 물리 에이전트 신원 연동, per-agent 정책 할당, 사전 집계와 서버 측 상세 페이지화를 별도로 검증해야 한다.
