# 한국 AI 기본법 조치 문서의 원본 검증 경로

2026-09-29. `KR-34-DOCUMENT`의 사람 판단과 기술 증거 상태를 분리하고, 제34조 조치 근거 문서의 실제 바이트를 접수·검증·복구하는 로컬 경로를 구현했다.

검토자와 관리자만 문서당 최대 64 KiB의 원문을 등록·조회·내보낼 수 있다. 서비스는 요청 SHA-256과 수신 바이트를 대조하고, 테넌트와 내용 해시에 결합한 AES-256-GCM 암호문으로 저장한다. 서명 원장에는 시스템, 버전, 원문 해시, 메타데이터 스냅샷 해시, 접수자·접수 시각, 시행령 제27조제2항에 따른 5년 보관 기한과 한계를 남긴다.

평가의 `governance-document:<id>` 참조는 사용자가 입력한 해시를 신뢰하지 않는다. 당시 저장 원문을 다시 읽어 해시와 복구 가능성을 확인한 뒤 버전·원문 해시·스냅샷 해시를 고정한다. 문서 개정, 암호문 손상·삭제, 조회 사본 변조, 다른 시스템·테넌트 참조는 평가를 `review_required`로 전환하고 보완 과제 종결을 차단한다. 사람의 법률 적용·충분성 결론은 기술 상태와 별도로 보존한다.

vault backup은 현재 문서뿐 아니라 서명 원장에 남은 모든 거버넌스 문서 버전의 암호문을 포함한다. 복구 전후 원장, 조회 사본, 파일 inventory와 원문 해시를 다시 검증하며 새 디렉터리에만 게시한다. 이 결과는 로컬 snapshot 복구 검증이며 실제 5년 경과 보존, 외부 WORM, KMS, HA 또는 법률 충분성 인증이 아니다.

검증 결과:

- 전체 Node 회귀 첫 실행: 480개 중 476개 통과. 4개 실패는 Windows 자식 서버의 `listen EFAULT` 3건과 그 OIDC 부모 suite 집계였다.
- 실패 파일 분리 재실행: 18/18 통과.
- 거버넌스 문서·정책·복구 집중 검증: 32/32 통과.
- 새 이미지 `evidscope:enterprise-20260929-r2`: `sha256:5ece0fed8bc670a62a71f2b5287614470dcda7575ec529d12faa9e1b72252d00`.
- 이미지 내부 제품 코드를 비루트, 읽기 전용 루트, CPU 2, RAM 1 GiB, 외부 네트워크 차단 조건에서 검증했다. 테스트와 운영자 CLI harness만 읽기 전용으로 마운트한 문서·HTTP·backup/restore·CLI 검증 22/22가 통과했고 테스트 컨테이너는 제거됐다.

전역 `/api/integrity`는 모든 문서 파일을 매번 읽지 않는다. 실제 원문 검증은 문서 조회, 평가 보고서, 과제 종결 및 backup/restore 경로에서 수행한다.
