# 한국 거버넌스 공개 학습 출처 감사

확인일: 2026-10-06. 범위: 공식 기관의 공개 한국어 질의응답과 해당 자료의 이용 허가. 읽기 전용 웹 조사이며, 전체 데이터셋 다운로드·학습·GPU 실행·런타임 수정은 하지 않았다.

## 결론과 승인 경계

**개별 HTML 본문에 공공누리 제1유형이 명시된 개인정보보호위원회 사람 질의응답 3개 문서를 확인했다.** AI 기본법에 직접 대응하는 과기정통부 지원데스크 사례집도 실제 존재한다. 그 발표 게시물에는 제1유형과 AI 학습 가능 표시가 모두 있으나, 첨부 ZIP/PDF 원문을 열지 못해 파일 내부의 권리 예외·실제 문항을 확인하지 못했다. 따라서 HTML 적격 후보와 첨부 파일 확인 대기를 구분한다.

이 조사의 ‘적격 후보’는 공개된 사람 발언·기관 출처와 본문 이용 허가를 확인했다는 뜻이다. **행별 독립 인간 검수 인증이나 EvidScope의 사람 검토 완료를 뜻하지 않는다.** 기관 발행 또는 이름이 있는 답변자를 근거로 `localHumanReviewPerformed=true`를 기록하지 않는다. 원문 추출·해시 고정·개인정보 검사·법령 버전 대조·분할을 수행하지 않았으므로, 이번 조사에서 학습 입력으로 확정한 행은 **0건**이다. 기존 모델의 한국법 전문성을 입증하는 결과도 아니다.

## AI 기본법 직접 자료: 게시물 허가 확인, 첨부 원문 확인 대기

가장 우선할 자료는 [과기정통부 지원데스크 사례집 발간 게시물](https://www.msit.go.kr/bbs/view.do?bbsSeqNo=94&mId=307&mPid=208&nttSeqNo=3187094&pageIndex=2&sCode=user&searchOpt=ALL&searchTxt=)이다. 인공지능 안전신뢰정책과 담당자가 명시되고, 보도자료 HWPX와 **사례집 ZIP**이 첨부되어 있다. 해당 게시물 바로 아래에 **‘제1유형: 출처표시’와 ‘AI 유형: 인공지능 학습 가능’**이 모두 명시되어 있다. 사이트 공통 푸터에서 추정한 허가가 아니다.

[KOSA 지원데스크 원문 게시](https://www.sw.or.kr/site/sw/ex/board/View.do?bcIdx=65415&cbIdx=390)는 **2026-03-31** 등록과 담당자, 사례집 PDF 첨부를 확인할 수 있다. [공식 KDI 수록 안내](https://eiec.kdi.re.kr/policy/materialView.do?num=278728)는 MSIT 자료의 발행 기관과 2026-04-01을 표시하고, **질의응답 주요 20건** 및 FAQ·심층 답변을 설명한다. **552건은 접수된 상담 수이며 학습 문항 수가 아니다.** 20건도 추출·적격 판정을 완료한 학습 행 수가 아니다. KDI 페이지의 131p 표시를 최종 학습 자료 규모로 사용하지 않는다.

남은 확인은 (1) MSIT ZIP과 KOSA PDF 원문 동일성·해시, (2) 실제 20선/FAQ의 원문 질문·답변 및 근거 범위, (3) PDF 내부의 저작권·제3자 자료 예외, (4) 게시물의 AI/제1유형 허가가 해당 첨부에 연결되는 증거 보관, (5) 시행 이후 개정법과 다른 부분이다. 웹 도구의 KOSA PDF·KDI PDF 첨부 열기는 `Internal Error`로 종료됐고, Windows 읽기 전용 HTML 요청도 DNS ‘알려진 호스트가 없습니다’로 실패했다. 이 접근 실패를 라이선스 불허나 자료 부재로 판정하지 않았다. 원문을 확보하기 전 첨부를 학습 적격으로 승격하지 않는다.

## 허가 조건을 데이터에 연결하는 방법

[한국저작권위원회 공공누리 유형 안내](https://www.copyright.or.kr/gov/nuri/guide/index.do)는 제1유형의 출처 표시, 상업·비상업 이용, 변형 가능을 설명한다. AI유형은 별도 조건을 가진 인공지능 학습 목적 허가이며, 실질적으로 유사한 산출물 방지, 직접 인용 시 출처 표시를 위한 기술적 조치, 학습용 데이터 재판매 금지 등을 명시한다. **일반적인 유형 안내는 개별 자료의 허가를 증명하지 않는다.** 실제 표시된 유형과 사용할 경로를 함께 기록해야 한다. 기관이 제품을 보증·후원한다는 표현도 사용하지 않는다.

후속 준비에서는 다음을 구분한다.

1. 원문 URL·게시일·발행 기관·자료 식별자·본문/파일 해시와 해당 자료의 허가 문구/표시를 고정한다. 웹 탐색 결과의 요약문을 원문 학습 정답으로 쓰지 않는다.
2. 기존 사람 질문과 사람 답변의 연속 원문만 추출한다. 사회자 발언·빈 질문·`***`로 핵심이 누락된 질문·답변 없는 문항은 배제한다. 짧은 후속 질문에는 실제 앞선 대화 범위를 함께 연결하며 새로운 질문이나 답변을 생성하지 않는다.
3. 개인정보 검사는 연락처가 있는 페이지 머리말과 본문 사례를 구분하고, 불필요한 담당자 전화·이메일을 학습 입력에 넣지 않는다. 기관 답변의 날짜·사건 범위와 인용 근거를 보존한다.
4. 같은 문서·사건·대화·번역 가족을 한 분할에 묶는다. 작은 3개 브리핑으로 충분한 독립 법률 평가 세트를 확보했다고 주장하지 않는다. 실제 확보 건수에 따라 분할 규모를 결정한다.
5. 공개 기관 작성 여부와 행별 인간 검수 확인 여부, EvidScope 자체 검토 여부를 별도 필드로 둔다. `localHumanReviewPerformed=false`, `qualityClaimAllowed=false`, `promotionAllowed=false`를 유지한다. 행별 검수 조건이 필요한 기존 학습 게이트를 임의로 통과시키지 않는다.

법령 적용성·증거 검증은 규칙과 담당자 판단에 남긴다. 이 자료의 목적은 한국어 원문 근거를 정리하고 설명하는 학습 후보를 확보하는 것이다. 현재 일반 한국어 Q/A 모델의 평가 개선을 AI 기본법 전문 학습 완료나 금융 감사 품질 인증으로 연결하지 않는다.

## 작업 결과

- 자료별 허가와 인간 발언 출처를 확인한 HTML Q/A 후보: **3개 문서**.
- AI 기본법 직접 사례집: **실제 공식 발행과 발표 게시물의 제1유형/AI 표시 확인**, 첨부 원문 검사 대기.
- 학습 행 추출·파일 다운로드·데이터 해시/분할 고정·새 학습 실행: **없음**.
- 코드·기존 데이터·동결 런타임·GPU/컨테이너/PVC 변경: **없음**.
