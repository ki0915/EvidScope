# 기업 운영 강화: 한국법 근거·증적 파기·복구

2026-09-22. 실제 결함 재현과 수정, 로컬 복구 도구를 추가했다. **최종 전체 테스트 280/280 통과**이며 전체 기업 운영 목표는 아직 완료하지 않았다. 실제 금융 고객 데이터를 사용하지 않았다.

## 변경과 근거

1. **위조 승인으로 증적 파기되는 경로 차단.** 원장에는 pending인데 조회 사본만 approved로 바꾸면 암호화 키 파기가 성공하는 결함을 재현했다. 보존 정책·hold·파기 계획·사건을 서명 원장과 대조한 후 승인·해제·파기를 수행한다. 사본의 변경·추가·누락·ID 불일치는 거부한다. 일반 사건 의견 추가를 통해 변조된 closed 상태가 재서명되던 경로도 기존 workbench 검증을 재사용해 차단했다.
2. **SQL 테넌트·순번 연결 강화.** 원장 및 체크포인트의 서명 본문은 그대로 두고 SQL tenant/seq만 변경한 경우에도 거부한다. 전체 bundle·이벤트 원본·보존·백업 경로에서 잘못된 테넌트 권한으로 사용하지 못하도록 Store 공통 경로를 보완했다.
3. **공급 당시 모델·목적 확인.** 현재 모델·증빙만 맞고 공급 당시 용도가 다른 경우가 기술적 일치로 표시되던 문제를 수정했다. suppliedModelVersion/suppliedPurpose의 미확인·불일치는 재검토로 남기고 충분 평가를 차단한다. 한국어 화면에서 구체 사유를 표시한다. 변경 자체를 법 위반이나 중대한 변경으로 확정하지 않는다. [시행령 제27조제3항](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0027&lsiSeq=288781&urlMode=lsScJoRltInfoR)을 원래 목적·용도 검토의 근거로 재확인했다.
4. **암호화 백업·실제 복구 추가.** 실행 중인 SQLite WAL 상태에서 backup API snapshot을 만들고 과거 revision의 공급사 문서를 함께 보존한다. DB는 AES-256-GCM 암호화, manifest는 서명한다. 별도 공개키와 회차별 외부 anchor로 검증하여 새 경로에만 복구한다. 두 테넌트, 기존 서명 보고서, 과거 문서, 이미 파기된 이벤트 키 상태를 검증했다. CLI 실행과 복구한 HTTP vault의 문서 조회·타 테넌트 접근 거부도 시험했다. [실행 방법과 한계](../docs/vault-recovery.md)
5. **배포 검사의 재시도 간격 수정.** 준비 상태 검사에서 120ms 남은 기한이 1초 재시도 간격을 줄이던 경계 오류를 수정했다. 다음 허용시각이 기한 안일 때만 재시도하며 monotonic clock으로 타이머 조기 깨움을 확인한다. 테스트 허용치를 완화하지 않았다.

한국법 및 증적 보안은 별도 에이전트가 독립 검토했다. 복구 도구의 독립 검토에서는 SQL 테넌트 연결 누락, 개발 실행 기록 사본 대조 누락, 대소문자 ID의 정렬 차이를 추가로 발견해 모두 수정·회귀했다. 서명·해시·복구 성공은 출처 진실성·법률 충분성 판단을 대체하지 않는다.

## 학습과 미완료 목표

선택한 Foundation-Sec-8B-Reasoning은 기존 checkpoint-5까지 학습돼 있고, 20 step 및 동일 베이스 후평가는 아직 미완료다. 이번 turn의 실제 조회에서 마지막 부팅은 2026-09-21, pagefile 설정은 16~24GiB지만 현재 할당량은 7GiB였다. 새 학습 Job을 만들지 않았고 DLP 클러스터는 실행 상태를 유지했다. 재부팅 후 같은 체크포인트와 고정된 provenance로 재개한다. [학습 실행 기록](public-qa-training-execution-20260922.md)

기업 운영 완료를 주장하지 않는다. 운영 OIDC/SSO, 자격 회수와 권한 갱신, 전체 API 사본 신뢰 경계, 원격 불변 보관·KMS·키 회전, 백업 보존/파기, 대용량 RPO/RTO·HA·배포/부하/SLO, 실제 공급자·금융 업무 연동, 모델 품질과 한국어 검토, 경쟁 도구의 동일 조건 실증이 남아 있다. 로컬 복구 성공을 원격 재해복구나 5년 보존 실적으로 간주하지 않는다. [원래 목표의 완료 기준과 남은 작업](../.planning/enterprise-goal-status.md)을 유지한다.
