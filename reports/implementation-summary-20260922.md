# 대출·신용평가 AI 증거 검증 구현 결과

2026-09-22. 한국 AI 기본법의 적용 후보와 운영 증거를 연결하는 첫 구현을 완료했다. 실제 금융 고객 데이터는 사용하지 않았다. 정식 모델 학습과 운영 환경 검증은 완료하지 않았다.

## 구현 범위

- 제31조의 사전 고지·생성형 결과 표시·사실적인 합성물 고지를 분리했다. 미확정 사실은 사람 검토 대상으로 남긴다.
- 당시 조직 정책의 건별 승인 요구를 기준으로 승인 누락을 판단한다. 정책이 미확정이면 승인 필요 여부도 미확정으로 표시한다.
- 금융 시스템의 공급사·모델·목적·사업자 역할을 등록하고 기존 기록은 미확인 사실을 보존해 재검토 대상으로 이관한다.
- 공급사 증빙 JSON 가져오기·내보내기, 테넌트별 암호화 로컬 문서 보관, 실제 복구·해시 검증, 모델·목적·증빙 변경에 따른 재검토를 연결했다. 공급사 조치 활용 후보는 제34조제1항제1~3호에 한정한다. 5년 보관 예정일은 정책 기록이며 5년의 실제 보존을 입증하지 않는다.
- 승인·실행·업무 결과를 인증 출처와 요청·시도·대상·버전·시각에 따라 대조한다. 연결과 시각 순서가 불확실하면 판단을 보류한다. AGT 수신 어댑터는 기존 수집 인증을 사용하며 별도 승인 엔진을 만들지 않는다.
- 감사 화면과 서명된 보고서에 법령 목록 해시, 시스템·증거 버전, 충돌·누락과 사람 판단을 고정한다. 조회용 데이터 변조를 새 보고서로 재서명하지 못하도록 원장과 대조한다. 서명은 내용의 진실성이나 법률 준수를 보증하지 않는다.

## 검증 결과

| 검증 | 결과 | 범위와 한계 |
|---|---|---|
| 최종 Node 전체 테스트 | 223/223 통과, 실패·건너뜀 0 | 최종 변경 상태에서 단일 실행 |
| Python 학습 산출물 테스트 | 13/13 통과 | 파일·해시·체크포인트 검증, 실제 GPU 학습 아님 |
| 합성 금융 업무 파일럿 | 8/8 통과 | 별도 프로세스 생산자, IPC를 통한 HMAC 서비스 경계; 실제 금융 환경 아님 |
| HTTP 통합 | 전체 테스트에 포함, 통과 | 인증·테넌트·문서 업로드·보고서 서명·재시작 후 복구 |

## 학습 준비와 남은 작업

**후속 실행 기록:** 아래는 초기 구현 당시 상태다. 이후 공개 KLUE 데이터로 실제 가중치 학습을 수행해 5 step 체크포인트를 보존했다. 20 step 완료는 자원 제한으로 미완료이며, 최신 결과와 복구 상태는 [공개 데이터 학습 실행 결과](public-qa-training-execution-20260922.md)를 참조한다.

금융 감사 7종 540건을 작성했다. 학습/검증/평가 분할은 300/60/180이며 한국어 출력은 360건이다. 같은 사건의 번역본은 분할을 공유한다. 전부 미검토·미승인 상태이며 학습 사용을 승인한 것으로 표시하지 않았다.

선택한 Foundation-Sec-8B-Reasoning과 Kubernetes 경로를 유지한다. 이미지·볼륨 준비 도구, NF4 QLoRA 설정, 10 optimizer step 체크포인트, 재개 시 베이스·데이터·설정 결합, 실제 adapter 파일·해시·step 검사, 동일 Reasoning 베이스의 adapter 적용 전후 순차 평가 코드를 추가했다.

이번 관측에서는 Docker 연결 불가, 유휴 시간 190초, 가용 RAM 15.09GiB, VRAM 1065/12288MiB로 시작 조건을 충족하지 못했다. NVIDIA WDDM 작업 목록은 그래픽·미분류 작업을 포함할 수 있어 활성 ML 작업 수로 단정하지 않는다. 사람 검토 완료 데이터도 0건이다. 이미지 빌드·가중치 다운로드·Pod 실행·정식 학습·학습 품질 측정은 수행하지 않았다.

남은 순서는 사람의 데이터 검토, 실행 가능한 Docker/기존 Kubernetes 환경 준비, 실제 CNI·GPU·종료 격리 검사와 자원 파일럿, 체크포인트 재개 실측, 정식 학습, 같은 베이스의 평가다. 기존 Kubernetes 작업 설정은 변경하지 않았다.
