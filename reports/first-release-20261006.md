# EvidScope v0.1.0 1차 출시 결과

출시일: 2026-10-06. **통제된 로컬/폐쇄망 파일럿 출시본**이다. 한국 AI 기본법 적용 후보·조치 근거, 인증된 운영 기록, 문서 보관·복구, 사람 검토, 재검토 과제와 서명된 감사 보고서를 하나의 실행 가능한 제품 흐름으로 제공한다. ZIP을 설치한 복사본에서 실제 반복 검사 **10/10회·각 38개·총 380개**, 배포된 전체 검사 **756/756**, Linux 출시 이미지 **38/38**을 통과했다. 법적 준수 인증이나 실제 금융기관 운영 실증을 출시 완료로 계산하지 않는다.

## 제공물과 실행

- `releases/evidscope-0.1.0.zip`: 소스·화면·실행 도구·Node 24.15.x용 고정 의존성·설치 안내·검증 결과·파일 해시를 포함한 설치 패키지. Node 실행 파일은 설치해야 한다.
- `releases/evidscope-0.1.0/`: 동일 내용을 확인할 수 있는 배포 디렉터리. 개인키·자격·DB·학습 가중치는 배포하지 않는다.
- `releases/evidscope-0.1.0-image.tar`: 실제 export/load를 확인한 서버 Docker 이미지. 이미지에는 서버만 있으며 초기화·실행·백업·검증 CLI는 별도 ZIP에 있다. 기존 TLS·자격·볼륨을 준비한 명시적 배포 경로에서 사용한다.
- [설치·첫 검토 안내](../docs/first-release-20261006.md), [한국법 근거 계약](../docs/kr-governance-evidence.md), [법령 확인 범위](../docs/legal-sources.md).

새 디렉터리에 ZIP을 풀고 동봉 의존성을 유지한 채 다음을 실행한다. 새 로컬 자격·키는 최초 시작에만 생성한다. 기존 데이터를 다른 파일럿으로 복사하거나 기존 프로세스를 임의 종료하지 않는다.

```powershell
node --version
$env:EVIDSCOPE_LOCAL_HOST='::1'
npm start
```

기본 감사 화면은 `http://[::1]:8082`. 로그인은 새 `.local/config.json`의 역할별 token을 화면에 직접 입력한다. 검토자는 alpha-reviewer, 읽기는 alpha-auditor, 분리 승인은 alpha-admin을 사용한다. 환경 HOST/DIR/PORT_BASE를 같은 값으로 지정한 별도 터미널에서 `npm run demo`로 합성 사례를 추가할 수 있다. 모델·GPU·학습 Job은 시작하지 않는다. 외부 GitHub·npm·이미지 레지스트리에 공개 게시하지 않았으며 현재 `private:true`, `UNLICENSED`에 맞는 통제된 전달이다.

## 출시 전 수정

실행기는 숫자 loopback, 사용자 지정 로컬 경로·기준 포트와 IPv6 주소를 지원한다. 각 서버의 준비를 제한 시간 안에서 확인하고 시작 실패·사용자 종료·예상 못한 자식 종료 때 자신이 시작한 자식만 회수한다. 기존 1초 후 강제 부모 종료를 제거하고 서버의 정상 종료를 기다린 뒤 필요한 경우 자신의 자식에만 강제 종료를 적용한다. 같은 자격·키·DB로 재시작되는 것을 확인했다. 로컬 HTTP 실행기에 상속된 TLS 변수 때문에 HTTPS 서버를 HTTP 주소로 잘못 안내하던 문제도 시작 전 명시적 거부로 수정했다.

합성 데모 CLI는 실행기와 같은 HOST/DIR/PORT_BASE를 사용한다. 금융·거버넌스 보고서 검증 CLI는 별도로 전달받은 Ed25519 공개키와 canonical snapshot hash를 사용하고, 원문에 들어 있는 공개키를 신뢰하지 않는다. 선택적인 외부 고정 보고서 해시는 과거 정상 보고서 재사용을 검출하는 기준이다. 전체 원장·체크포인트 검증과 원문의 진실성은 별도 범위다.

이미지: `evidscope:0.1.0`, ID `sha256:f406c0b1fd9a2b53a8fbc466fc5a56857ce4f0a3c1724f21f4df53e95fd49c5b`. 소스와 로그 해시는 배포 manifest 및 최종 [출시 영수증](first-release-20261006/release-receipt.json)에 고정한다. ZIP의 코드·법령·화면·역할·실행기·검증기가 10회 검사에서 확인한 102개 소스 해시와 일치해야 출시 패키징을 허용한다. 회차별 38개 결과·종료 확인·로그 해시도 검증하고, 한 번이라도 실패하거나 코드가 바뀌면 PASS를 만들지 않는다.

회차마다 독립 ingress/vault/audit와 실제 worker를 구동하는 실행기 경로를 확인했다. 위조 서명·잘못된 출처·다른 tenant·중복 접수, 시스템 등록, 실제 보관 문서의 4MiB 상한 및 복구, 근거 없는 종결 거부, 모델 변경 후 재검토와 과거 보고서 보존, 별도 키·외부 hash 및 원장 검증, 암호화 백업·새 경로 복구, 데이터 유지 재시작, 포트 충돌 후 자신이 시작한 프로세스만 회수하는 흐름을 포함한다. Linux에서는 실제 SIGINT 종료도 확인했다. Windows 자동 반복은 동일 종료 처리기의 IPC 종료 경로를 사용했다.

최초 설치에서 개발 PC의 전체 실험 검사까지 실행한 결과는 **752/759·실패 7**이었다. [원본 로그](first-release-full-regression-20261006.log)를 보존했다. 6건은 배포하지 않은 `.local` 학습 자료·모델 잠금·과거 실행 영수증을 요구했고, 감사 AI API 검사 프로세스 1건은 상세 원인 없는 실패였다. 후자는 [분리 6/6 검사](first-release-assistance-diagnosis-20261006.log)와 이후 10회·최종 전체 검사 모두 통과했으며 원인을 자료 누락으로 바꾸지 않았다.

실제 학습 실험 전용 3개 파일의 **8개 검사**를 출시 테스트에서 제외한다. 그중 자료 누락으로 실패한 6개와 같은 파일의 전처리 검사 2개를 포함한다. 해당 파일명과 이유는 release-manifest.json에 명시한다. 출시본에 자격·실험 자료·학습 가중치를 넣어 성공으로 만들지 않았다. 모델 훈련 및 새 후보의 품질 승격은 별도 연구 검증이다. 배포된 테스트에는 skipped/todo가 없다.

## 완료 범위와 운영 경계

현재 한국 요구사항 18개·조치별 시험 유형 20개·시스템 schema 4를 제공한다. 요구사항과 실제 기술 근거, 사람의 적용성·충분성 판단을 구분하고 모르는 사실은 unknown으로 유지한다. 미래 완료 시각·미확인 시계·다른 모델/명령의 기록·복구할 수 없는 문서는 성공 근거로 사용하지 않는다. 5년은 조치 문서 보관 정책·메타데이터와 복구 시험이며 실제 5년 경과 실적이 아니다.

실제 금융기관/기관 접수·최종 고시 전체·원격 DMS/KMS/WORM·저장소 HA·조직 SSO의 실연동·회사 단위 대리인 사건·신규 모델의 생성 품질 승인은 후속이다. 이번 출시는 해당 항목을 완료로 포장하지 않으며 서명·기술 시험만으로 법률상 준수 또는 인증을 발급하지 않는다. 전체 엔터프라이즈 목표는 progress지만 이번 1차 통제된 파일럿 배포본과 명시된 출시 검증은 완료했다.
