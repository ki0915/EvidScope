# 한국 AI 기본법 최종 고시·지침 출처 완전성 점검

확인일: **2026-10-06**. 범위: 현재 `data/requirements.json`, `docs/legal-sources.md`와 법 제31·33·34조, 시행령 제23·25·27조에 관련된 공식 공개 출처. 생산 코드·테스트·학습/GPU·배포·PVC·릴리스는 변경하지 않았다. 이번 결과는 제한된 출처 감사이며 법률상 충분성 또는 인증이 아니다.

## 결과

기존 최종 고시·위원회 결정의 **미확인 상태를 확인됨으로 바꿀 새 원문을 확보하지 못했다**. 공식 가이드 배포 상태와 법률·시행령은 재확인했다. 미검색·접근 실패를 해당 고시나 결정의 부존재로 해석하지 않는다.

현행 제31·33·34조 조문 페이지는 법률 **제21311호, 2026-01-20 일부개정**, 해당 조문 **2026-01-22 시행**을 표시한다. 현행 시행령 관련 조문은 대통령령 **제36580호, 2026-08-18 타법개정, 2026-08-20 시행**이다. 이 출처 확인일을 조문 효력일로 사용하지 않는다. 현재 등록부의 `verified_statute_and_decree`는 해당 법률·시행령 확인 상태이며 모든 세부 고시와 위원회 결정까지 확인했다는 뜻으로 확대할 수 없다.

## 가이드의 현재 공식 배포 상태

[NIA 공식 배포 페이지](https://www.nia.or.kr/site/nia_kor/ex/bbs/View.do?bcIdx=28987&cbIdx=99835&parentSeq=28987)는 최초 **2026-01-22** 게시이며 하위법령 가이드의 현재본 공개를 명시한다. 현재 첨부 목록에서 다음 파일 버전을 확인했다.

- 투명성: `260126`, 2026-01-27 수정본 업로드 안내(텍스트 서비스 예시 수정).
- 고영향 판단: `260429`, 2026-04-29 수정본 안내(보건 의료 판단 절차도 수정). 1월 29일·2월 13일 이전 수정 이력도 보인다.
- 고영향 사업자 책무: `260122`.

현재 `docs/legal-sources.md:50–60`은 이 버전들과 과거 본문 확인 범위·해시를 이미 구별해 기재한다. 이번에는 배포 페이지 본문·파일명·수정 안내를 새로 확인했으며 **PDF 3개 다운로드 클릭은 도구 내부 오류**였다. 따라서 이번 조사에서 파일 바이트 동일성, 해시, PDF 본문 전체를 새로 확인했다고 보고하지 않는다. 가이드 공개 상태를 고시 공포·법적 효력 또는 운영 이행 인증으로 사용하지 않는다.

## 새로 확인한 최종 고시의 범위 혼동 방지

[인공지능제품·서비스 확인 절차 운영에 관한 고시](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000283290&chrClsCd=010202)는 **과학기술정보통신부고시 제2026-50호, 2026-07-21 제정·시행**임을 공식 행정규칙 표제에서 확인했다. 공식 검색 결과에 노출된 제1조는 법 **제16조제3항**, 시행령 **제15조제4항제1호**의 AI/AI기술 활용 여부 확인을 근거로 한다. 전체 본문을 반환하지 않은 페이지 대신 해당 제1조 노출 범위만 사용했다.

이 고시는 **법 제33조의 고영향 해당 여부 확인 고시가 아니다**. 따라서 이 고시 번호·확인기관·확인서만으로 `KR-33` 고영향 장관 확인 완료나 제34조제1항제6호 추가 조치 완료를 주장할 수 없다. 이번 범위의 미확인을 제거할 근거가 아니다. 이후 공식 확인서 수집을 확장할 때 확인 종류·위임 조항을 검사하는 좁은 회귀 사례가 필요하다.

## 해결되지 않은 출처와 접근 한계

공식 도메인(`law.go.kr`, `msit.go.kr`, `aikorea.go.kr`, `gwanbo.go.kr`, 관련 `korea.kr`)으로 한정하여 책무 최종 고시, 투명성 추가 예외, 제34조제1항제6호·위원회 의결을 검색했다. 정확한 고시/의결 번호·확정일·효력일·첨부 원문을 새로 확보하지 못했다. 다음 실패 때문에 공개 목록 전수검색 완료를 주장하지 않는다.

- [과기정통부 훈령예규고시 목록](https://www.msit.go.kr/bbs/list.do?mId=108&mPid=103&sCode=user)은 도구 출력에 총 건수·목록 틀만 표시되고 실제 각 행은 보이지 않았다. 검색어를 적용한 목록 URL은 접근 오류였다.
- [위원회 공식 홈페이지](https://www.aikorea.go.kr/)와 [사이트맵](https://www.aikorea.go.kr/web/sitemap.do?menu_cd=000016)은 위원회 활동의 구조를 표시했지만 구체적 회의·의결 문서는 반환하지 않았다.
- [전자관보](https://www.gwanbo.go.kr/)는 본문 0줄을 반환했다. 관보 검색·첨부 원문 확인 완료가 아니다.
- 국가법령정보센터의 책무/안전성 고시 제목 직접 URL은 접근 오류였다. 이는 고시 부존재를 증명하지 않는다.

따라서 제34조제1항제6호, 제34조제2항 최종 구체화 고시, 시행령 제23조제4항제3호 추가 예외, 제25조제2항제5호 추가 판단 사항은 **미확인**이다. 현재 다섯 `KR-34-*` 레코드의 기술 근거가 지원 상태여도 제6호까지 전체 한국법 지원이 완료되었다고 합산할 수 없다.

## 다음 구현은 출처 확보 후 좁게 진행

1. 관보/부처 최종 원문 또는 위원회 의결 첨부에서 정확한 **문서 종류, 위임 조항, 발령·의결번호, 공포/의결일, 효력일, 현재 버전**을 확보한다. 최종성 판별은 제목보다 본문·부칙을 사용한다. 원문을 얻기 전 해당 법률 미확인 표시는 유지한다.
2. 실제 제34조제1항제6호 결정이 확인되면 그 결정이 요구하는 조치만 독립 요구사항으로 매핑하고, 기존 다섯 조치나 장관 가이드 권고와 구분한다. 초안·다른 확인제도의 고시를 입력했을 때 지원 완료가 되지 않는 회귀 사례를 먼저 구성한다.
3. 새 기준 버전 적용은 과거 signed 평가·보고서를 보존하고 영향을 받는 시스템에 재검토를 연결한다. 전체법 지원율에는 조문별 구현 상태와 **하위 출처 미확인**을 별도로 표시한다. 실제 기관 확인이나 법률 충분성 판정은 별도 사람 검토로 유지한다.

이번 범위에서는 확정 원문 부재로 새 법적 의무·예외를 생산 코드에 추가하지 않았다. GPU 평가 중 로컬 작업은 작은 파일 읽기와 이 보고서 작성만 수행했다.
